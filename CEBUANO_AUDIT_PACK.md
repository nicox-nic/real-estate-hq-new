# Real Estate HQ — Cebuano Audit Pack

This document compiles all Cebuano content generated by the prototype across three surfaces:

1. **Content Studio templates** (12 types × Cebuano variant)
2. **AI Reply Suggester** (Cebuano translation of suggested replies)
3. **Share Message Generator** (Cebuano variants of buyer share messages)

## How to use this pack

Hand this file to a Bisaya/Cebuano native speaker. For each entry:

- Read the **English source** for context.
- Read the **Cebuano output** generated by the prototype.
- Apply the reviewer checklist at the bottom.

The prototype uses programmatic `applyLanguage(text, "Cebuano")` which wraps content with "Maayong adlaw" opener and "Salamat kaayo" closer. The body is currently kept in English with Cebuano framing — full body translation will need either an LLM (see LLM_INTEGRATION_NOTES.md) or a human pass before launch.

## Reviewer Checklist

For each Cebuano output above, check the following:

### Structural correctness (already verify-locked in the prototype)

- [x] Output uses Cebuano opener (e.g., "Maayong adlaw") — NOT Tagalog "Kumusta po"
- [x] Output does NOT use the Tagalog particle "po"
- [x] Output uses Cebuano closer where present (e.g., "Salamat kaayo")

### Naturalness (the human audit)

- [ ] Phrasing reads naturally to a native speaker (not literal English-to-Cebuano substitution)
- [ ] No Tagalog-isms (e.g., "kaya" used as Tagalog, "tayo" instead of "kita")
- [ ] Regional register is appropriate for a real estate sales context (formal-friendly, not slang)
- [ ] Honorifics and pronouns are consistent with buyer relationship (formal "ka" / "ikaw" vs. "kayo" for elders)
- [ ] Code-switching where appropriate (e.g., keeping "₱18.5M" and "4BR" in English numerals is natural; translating those would feel unnatural)

### Real-world value

- [ ] A Bisaya buyer would feel comfortable receiving this message
- [ ] An agent sending this would feel professionally represented
- [ ] The Cebuano framing adds value vs. just sending English

## Notes for the implementation team

- The Cebuano support is currently **programmatic framing**, not full-body translation. The 4-pronged language structural proof in verify Section 22 locks correctness of the framing (Maayong present, no po, three pairwise distinct) but does NOT lock full Cebuano body grammar.
- The Session 9 polish ratification flagged Cebuano native-speaker audit as the right work for this stage; this pack is that work's input.
- For full Cebuano content generation, the recommended path is the LLM hookup described in `LLM_INTEGRATION_NOTES.md` sections 1 and 2 (AI Reply Suggester + Content Studio Templates).
- The English-only templates (Email Follow-up, Investment Pitch, Luxury Buyer Message) reflect a real-world Philippine real estate convention: formal written contexts often default to English. This is an honest scope decision, not a translation gap.
